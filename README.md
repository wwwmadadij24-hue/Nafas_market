# نفس مارکت – ربات تلگرام

این نسخه اولیه شامل ثبت‌نام، ثبت آگهی با وضعیت در انتظار تأیید، فهرست کالاهای تأییدشده، ثبت درخواست خرید و آمار پایه مدیر است.

## اجرای محلی یا روی میزبان پایتون
1. Python 3.10 یا جدیدتر نصب کنید.
2. وابستگی‌ها را نصب کنید: `pip install -r requirements.txt`
3. متغیر محیطی `BOT_TOKEN` را با توکن BotFather تنظیم کنید.
4. متغیر `ADMIN_ID` را با شناسه عددی تلگرام مدیر تنظیم کنید.
5. اجرا: `python main.py`

**مهم:** توکن ربات را در فایل‌های مخزن یا پیام عمومی قرار ندهید. آن را فقط در بخش Secrets/Environment میزبان وارد کنید. تا وقتی برنامه روی یک میزبان همیشه‌روشن اجرا نشود، ربات پاسخ‌گو نخواهد بود.

این نسخه پرداخت و دریافت کمیسیون خودکار ندارد؛ ثبت سفارش صرفاً درخواست اولیه است و مبلغ/کمیسیون باید خارج از ربات و با توافق شفاف طرفین مدیریت شود. قبل از استفاده عمومی، سیاست حریم خصوصی، شرایط فروش، کنترل آگهی و روش امن ارتباط خریدار و فروشنده را تکمیل کنید.
