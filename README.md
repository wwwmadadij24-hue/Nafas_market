# نفس مارکت – نسخه اولیه ربات تلگرام

این پروژه نسخه آغازین بازار نفس مارکت است. در این نسخه کاربران می‌توانند ثبت‌نام کنند، آگهی کالا ثبت کنند، کالاهای تأییدشده را ببینند و درخواست خرید بفرستند. مدیر می‌تواند آگهی‌ها را تأیید یا رد کند. پس از ثبت سفارش، به فروشنده و مدیر پیام اطلاع‌رسانی ارسال می‌شود.

## امکانات فعلی
- ثبت‌نام با نقش خریدار، فروشنده یا هر دو
- ثبت آگهی با وضعیت «در انتظار تأیید»
- نمایش آگهی‌های تأییدشده
- ثبت درخواست خرید
- اطلاع‌رسانی سفارش به فروشنده و مدیر
- تأیید یا رد آگهی توسط مدیر
- آمار پایه از طریق دستور `/admin`

## راه‌اندازی
1. Python 3.10 یا جدیدتر نصب کنید.
2. وابستگی‌ها را نصب کنید: `pip install -r requirements.txt`
3. در تنظیمات محیطی میزبان، دو متغیر زیر را تعریف کنید:
   - `BOT_TOKEN`: توکن دریافتی از BotFather
   - `ADMIN_ID`: شناسه عددی تلگرام مدیر
4. برنامه را با دستور `python main.py` اجرا کنید.

برای نمونه متغیرها، فایل `.env.example` را ببینید. فایل واقعی `.env` و توکن ربات را هرگز در GitHub بارگذاری نکنید.

## اجرای دائمی
در میزبان‌هایی که Worker یا Background Process دارند، دستور اجرای برنامه `python main.py` است. فایل `Procfile` نیز برای میزبان‌های سازگار اضافه شده است. برای نگهداری اطلاعات، فضای ذخیره‌سازی دائمی لازم است؛ در غیر این صورت ممکن است پایگاه داده SQLite با راه‌اندازی مجدد میزبان از بین برود.

## محدودیت‌ها و گام‌های بعدی
- این نسخه هنوز اپلیکیشن اندروید یا وب‌سایت کامل نیست؛ فعلاً هسته ربات تلگرام است.
- پرداخت آنلاین و محاسبه/وصول خودکار پورسانت پیاده‌سازی نشده است.
- پیش از انتشار عمومی باید روش تماس امن، سیاست حریم خصوصی، شرایط استفاده و پشتیبان‌گیری پایگاه داده تکمیل شود.
- هر معامله و پورسانت باید با اطلاع و توافق روشن خریدار، فروشنده و مدیر انجام شود.
